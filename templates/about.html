Project Objective

The system predicts total property price using cleaned and engineered features derived from Indian real-estate listings. It demonstrates how messy public data is transformed into a reproducible machine-learning and deployment workflow.

Key academic strengths

  • Genuine public dataset with documented source URL
  • Explicit leakage prevention
  • Train/validation/test model selection design
  • At least three regression models compared
  • Saved model + preprocessing pipeline
  • Web application and JSON prediction API
  • Render-ready deployment configuration
